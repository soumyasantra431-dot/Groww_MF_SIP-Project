# Groww first-year SIP discovery engine

This is a research workbench for the graduation brief, not an investing assistant. Its job is to examine permitted, source-linked accounts of mutual-fund SIP experiences; show what happened, what remains unknown, and which possible first-year situations deserve further investigation. It does not calculate Groww retention or select a final customer problem.

Start with [Problem Statement.md](Problem%20Statement.md), the [one-LLM architecture](architecture.md), and the [phase-wise implementation plan](implementation-plan.md). The [Phase 0 contract and measured baseline](PHASE_0_CONTRACT_2026-11-04.md) records the current decision, source access states, quality checks and remaining gaps. [Edge cases](edge%20case.md) cover unusual or ambiguous inputs.

**Current state, 7 November 2026:** The [public read-only viewer](https://sip-research-viewer.soumyasantra431.workers.dev/) is deployed on Cloudflare; its source code and checked snapshot are on GitHub. The local ledger has 103 rows: 100 public user-voice entries and three controls. Fifteen entries have assistant coding proposals, 31 distinct forum source units are locally usable, and zero individual sources or nine-question answers have passed the strict approval gate. A bounded review-collection audit reports at least 932 Groww cross-store review IDs retrieved, but only 309 mechanical MF/SIP topic candidates; these are not analysed investors. The Fellow endorsed nine short, source-linked readings and four unscored situations as provisional research directions. They appear in the public snapshot in a separate editorial lane, with zero approved findings. The Free-tier model path exists but failed its development extraction check (12/41 stated fields exactly recovered on eight episode items), so batch and live paste classification remain disabled. The public snapshot contains no raw posts, private survey data, credentials or accepted source records. Deployment verifies the research viewer, not Groww retention or AI accuracy.

The build order is permitted real-source intake → cleaning and duplicate control → lean one-LLM proposals → human review and nine evidence-bounded answers → independent quality evaluation → local evaluator check → privacy-safe public snapshot. Survey responses stay separate; synthetic examples test code only. No paid model mode is planned.

Run locally with `pnpm.cmd dev`; check code with `pnpm.cmd test` and `pnpm.cmd build`. Regenerate the safe, dated snapshot with `pnpm.cmd snapshot` and inspect it before publication. `public/snapshot.json` is gitignored by default; deliberately stage only a checked release version.
